# ТММ ДЗ 26 — Вариант 5 (Android)

Мобильное приложение для **отслеживания лица**, **углов Эйлера головы** и **оценки направления взгляда** по видеопотоку фронтальной камеры (близко к реальному времени).

**Корень репозитория** — эта папка (`2026-BMSTU-MMT`). Открывать в Android Studio именно её (`File` → `Open`).

## Реализовано

- Превью и анализ кадров через **CameraX** (`Preview` + `ImageAnalysis`).
- Детекция лица и контуров глаз — **ML Kit Face Detection** (on-device).
- Отображение углов Эйлера: **Pitch (X)**, **Yaw (Y)**, **Roll (Z)**.
- Оценка **3D-вектора взгляда** (Gx, Gy, Gz) с учётом ориентации головы (`PoseMath`).
- Визуализация: рамка лица, точки у глаз, условные оси головы, стрелка взгляда, текстовые значения.
- Экспоненциальное **сглаживание** углов и вектора для уменьшения дрожания.
- Обработка режима «лицо не найдено» (текст-подсказка, пустой оверлей).

## Требования

- **Android Studio** (в т.ч. линейка Panda или новее).
- **JDK**: для сборки Gradle подходит **JDK 17** или **Embedded JBR / JetBrains Runtime 21** из состава Android Studio (`Settings` → `Build Tools` → `Gradle` → `Gradle JDK`).
- Интернет при первой синхронизации Gradle.
- **SDK**: Platform **API 34**, Build-Tools, Platform-Tools, при работе без телефона — **Android Emulator** (образ API 34).

Целевая платформа приложения в `build.gradle`: `compileSdk = 34`, `minSdk = 24`.

## Запуск

1. `File` → `Open…` → выберите каталог **`2026-BMSTU-MMT`** (где лежат `settings.gradle.kts`, `app/`).
2. Дождитесь успешного **Gradle Sync**.
3. **Device Manager** → создайте/запустите эмулятор (например Pixel 6, Android 14) или подключите телефон с **USB debugging**.
4. Выберите конфигурацию **app** → **Run** (⇧F10).
5. Выдайте разрешение **Камера** при первом запуске.

### Эмулятор

Для виртуальной сцены/камеры используйте настройки эмулятора (Virtual Scene / камера), чтобы в кадр попало «лицо» — иначе будет сообщение «Лицо не обнаружено».

## Структура исходников

| Файл | Назначение |
|------|-------------|
| `app/.../MainActivity.kt` | Разрешения, CameraX, сглаживание, обновление UI |

## Полезное для сборки

- В `gradle/wrapper/` задан Gradle Wrapper (`gradlew.bat` под Windows): сборка возможна из IDE без ручной установки Gradle.
- Если при компиляции Kotlin ругались на **`surfaceProvider`**, в проекте для `Preview` используется вызов **`setSurfaceProvider(...)`** — это корректный API CameraX.
